01 · Overview

Project Overview

About the project

A Machine Learning classification system built on the Online Shoppers Purchasing Intention Dataset. It analyzes browsing activity, page durations, visitor types and other session information, and compares three classifiers using several metrics.

Why it matters

Millions of people visit online shops, but not every visitor buys. Understanding purchasing behavior helps businesses improve marketing strategies and customer experience.

What ML contributes

Machine Learning analyzes large amounts of historical session data, finds patterns linked to purchasing and non-purchasing behavior, and uses them to predict customer behavior.

02 · Problem & Objectives

Problem Statement and Objectives

Online shopping websites receive many visitors, but only a small proportion complete purchases. Without proper analysis of behavior, businesses struggle to identify visitors who are more likely to buy. This project develops a Machine Learning model that analyzes session information and predicts whether a visitor will make a purchase.
  1. Collect and understand a relevant dataset suitable for classification.
  2. Explore and analyze online shoppers' browsing behavior.
  3. Identify important features related to purchasing intentions.
  4. Perform data cleaning and preprocessing.
  5. Conduct Exploratory Data Analysis using statistics and visualizations.
  6. Implement Logistic Regression, Decision Tree and Random Forest.
  7. Train and test the selected models.
  8. Evaluate performance using appropriate classification metrics.
  9. Compare the performance of the implemented algorithms.
  10. Identify the most suitable model for predicting purchasing intentions.

03 · Dataset

Dataset Description

12,330original records
125duplicates removed
12,205cleaned records
17 + 1features + target

Source & target

Source: UCI Machine Learning Repository. Open the original dataset ↗

Target variable: Revenue. True = the visitor completed a purchase; False = no purchase. Class counts in the cleaned data: 10,297 No Purchase (84.37%) and 1,908 Purchase (15.63%).

Problem type: supervised Binary Classification (Purchase vs. No Purchase). The dataset has both numerical and categorical features and contains no missing values.

Preprocessing

  • Loaded into a Pandas DataFrame; no missing values found.
  • 125 exact duplicates removed with drop_duplicates().
  • Features (X, 17 columns) separated from target (y = Revenue).
  • Numerical (14): median imputation + StandardScaler.
  • Categorical (Month, VisitorType, Weekend): most-frequent imputation + One-Hot Encoding.
  • 80/20 stratified split, random_state=42: 9,764 training and 2,441 test rows.

09 · Discussion

Best Model and Discussion

Best overall model

Random Forest

Highest accuracy (0.8984), precision (0.6782), F1-score (0.6728) and ROC-AUC (0.9272). It was selected for its stronger overall performance across most evaluation metrics.

Recall vs. precision

Logistic Regression has the highest recall (78.53%), so it found more of the actual purchasing sessions. Random Forest has higher precision and F1-score, a better balance between finding purchases and limiting incorrect positive predictions.

Confusion matrices

Random Forest correctly classified 1,938 non-purchasing and 255 purchasing sessions, with the fewest false positives (121) of the three models.

Feature importance

PageValues is the most influential feature in the Random Forest model, followed by ExitRates and ProductRelated_Duration.

10 · Conclusion

Conclusion

What was achieved

Three classifiers were implemented and evaluated on the Online Shoppers Purchasing Intention Dataset using Accuracy, Precision, Recall, F1-Score and ROC-AUC. The objectives of the experiment were successfully achieved. Random Forest was selected as the best overall model with 89.84% accuracy and an ROC-AUC of 0.9272.

What was learned

Different algorithms have different strengths in predicting purchasing behavior, and Machine Learning can help e-commerce businesses understand visitor behavior and predict purchasing intentions.

Future work

Additional algorithms and optimization techniques could be explored to further improve prediction performance.
